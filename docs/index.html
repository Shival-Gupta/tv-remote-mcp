Getting Started

Step-by-step instructions to connect your smart TV with TV Remote MCP.

1. Network Prerequisites

Both your controlling device (phone, laptop, tablet) and your Smart TV must be connected to the same local Wi-Fi or LAN network.

Disable "Client Isolation" or "AP Isolation" in your Wi-Fi router settings if your phone cannot reach your TV's local IP address.

2. Zero-Install Web Remote

Roku streaming devices and Roku TVs can be controlled directly from your browser with zero installation.

  1. Open Shival-Gupta.github.io/tv-remote-mcp/remote/
  2. Input your TV's local IP address (e.g. 192.168.1.11).
  3. Select Roku as brand and tap Save & Connect.

3. Local Relay Server (For All Brands)

LG, Samsung, Android TV, Fire TV, Vizio, and Sony enforce native protocols (WebSocket, ADB, SOAP) that browsers restrict. Running the lightweight relay bridges this gap effortlessly.

# 1. Clone & install dependencies git clone https://github.com/Shival-Gupta/tv-remote-mcp.git cd tv-remote-mcp pip install pywebostv requests # 2. Run the relay server python server/relay.py

Pairing Recipes

How to authorize the remote control on your TV screen.

LG WebOS

When connecting for the first time, a dialog appears on your TV screen asking to allow the connection.

• Click Allow with your physical LG remote. The token is saved in tv-tokens/tokens.json automatically.

Android TV & Fire TV

Enable Developer Options by tapping Build Number 7 times in TV Settings → About.

• Turn on USB Debugging. When prompted on screen, check "Always allow from this computer" and accept.

Troubleshooting

Resolving common connectivity and network questions.

Why does my phone say "Relay required"?

Modern mobile browsers prevent web pages from establishing raw socket connections to internal LAN ports like 3000 (LG) or 5555 (ADB). Running relay.py on your computer acts as a secure local bridge.

How do I turn the TV ON if it is sleeping?

Ensure "Mobile TV On / Turn on via Wi-Fi" is enabled in your TV's power settings. TV Remote MCP will send a Wake-on-LAN (WOL) magic packet broadcast to power on your TV.
